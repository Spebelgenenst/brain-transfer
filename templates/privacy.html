Privacy Policy – Brain Transfer

1. Data Collection

We collect the following data when you use our service:

  • Uploaded files (audio, video, text) for processing purposes
  • Session identifiers to manage access to your files
  • CAPTCHA input solely for spam prevention (not stored)
  • YouTube URLs (only the video ID is extracted, not stored)
  • Technical data such as IP addresses and user agents for security checks (not stored permanently)

2. Purpose of Data Use

  • Process and convert uploaded files for download or streaming
  • Prevent abuse through CAPTCHA and file size limitations
  • Maintain temporary access to your files during your session

3. Data Retention

  • Uploaded files: Stored on the server and automatically deleted after 24 hours by a scheduled cleanup process
  • Session data: Access to your files is tied to your session. When your session ends (e.g., browser closure), access is revoked, but the files remain on the server until the 24-hour cleanup
  • No permanent storage of user data or file contents

4. User Rights

  • Access to your files is automatically revoked when your session ends
  • Files are permanently deleted from our servers after 24 hours
  • No user data is shared with third parties, except for YouTube embeds, which are subject to YouTube’s own privacy policy

5. Security

  • Files are processed locally and stored securely on our server
  • We do not log file contents or permanent user data

6. Changes to This Policy

We may update this Privacy Policy from time to time. We encourage you to review it periodically.

Effective Date: May 3, 2026 Jurisdiction: Germany (GDPR-compliant)
